# v1.78.0

Feeds can now prefer generated image descriptions over those supplied by the feed.

## Added

- **Per-feed AI alt text override.** Edit a feed and turn on **Prefer AI alt text over the feed's own** to request a vision description even when the feed item already has one. On success, that description replaces the feed-provided alt text on Mastodon, Bluesky, Matrix, and micro.blog image attachments.
- **Feed descriptions remain the fallback.** If the vision API is disabled, the request fails, or the provider returns an empty result, FeedEcho uses the feed-provided description. Enable AI alt text in Settings to use the override.
- **Existing behavior is unchanged by default.** The override is off for new and existing feeds. With it off, feed-provided descriptions win and the vision API is used only when the feed has none.

The `feeds.ai_alt_override` schema migration runs automatically at startup in both SQLite and Postgres installs. No new environment variables or manual configuration changes are needed.
