Retries & Failure Notifications

Failed deliveries retry automatically with exponential backoff. After the max attempts, the item is marked "Gave up" and the feed moves on. Notifications require SMTP to be configured above.

0 = retry forever
First retry delay; doubles each attempt
0 = notifications off

AI Alt Text (Optional)

When enabled, FeedEcho generates alt text for attached images using an OpenAI-compatible vision API. Requires a vision-capable model endpoint. If disabled or unconfigured, images are uploaded without alt text.

{% endif %}
