Connect Matrix

Post feed items into a Matrix room. Log the account you want to post as into any client, copy its access token (Element: Settings → Help & About → Access Token), and give the room's ID or alias. That account must already be in the room — FeedEcho posts as it, it never joins rooms for you. Connect one room per form submission.

Connect Discord

Post feed items into a Discord channel via a webhook. In Discord, open the channel you want FeedEcho to post to, then Server Settings (or channel settings) → Integrations → Webhooks → New Webhook → Copy Webhook URL, and paste it here. The webhook URL is a secret — anyone who has it can post to that channel, so treat it like a token.

Connect Webhook

Post feed items as JSON to any HTTP endpoint. Works with Slack and Mattermost incoming webhooks, ntfy and Gotify notifications, Zapier or n8n, or anything you run yourself. Each item arrives as one JSON object: text (your template output) plus title, link, summary, content, content_link, author, published, tags, image_url, image_alt, id, and feed_name. Custom headers are optional and go in one per line, like Authorization: Bearer your-token — header values are stored like credentials and are never shown again.
